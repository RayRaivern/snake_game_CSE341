# CSE341 Course Project
## Snake Game
Classic snake game written in x86 Intel 8086 Assembly.

## Main Features
1. **Graphics Rendering:** Render the game board, borders, snake, food, and score on the screen using 8086 Assembly and EMU8086.
2. **Keyboard Control:** Continuously detect keyboard input and allow the player to control the snake's direction using the designated keys.
3. **Snake Movement:** Manage the snake's head and body positions using an array and update its position according to the current direction.
4. **Collision Detection:** Detect collisions between the snake and the game-board boundaries or its own body and trigger the appropriate game-over behavior.
5. **Food Generation:** Generate food at valid positions on the game board, ensuring that food does not appear on the snake's body, and detect when the snake consumes it.
6. **Scoring System:** Maintain and display the player's score, increasing it whenever the snake consumes food.
